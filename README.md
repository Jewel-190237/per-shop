# Pet Shop Practice - Complete Pet Management System

A comprehensive pet shop management system built with React, Vite, Tailwind CSS, Ant Design, and DaisyUI. Features include pet listings, appointments, dashboard, and payment integration.

## Features

- Responsive design for all devices
- Pet listings and search functionality
- Appointment scheduling system
- Dashboard with analytics
- Payment integration
- User authentication
- Shopping cart functionality
- Review system
- Modern UI with Ant Design and DaisyUI

## Technologies Used

- **Framework:** React 18
- **Build Tool:** Vite
- **Styling:** Tailwind CSS, DaisyUI
- **UI Library:** Ant Design
- **Routing:** React Router DOM
- **Carousel:** Swiper
- **File Upload:** React Dropzone
- **Icons:** React Icons
- **Utilities:** LocalForage, Match Sorter

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/Jewel-190237/pet-shop-practice.git
   ```

2. Open the project folder:
   ```bash
   cd pet-shop-practice
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Start the development server:
   ```bash
   npm run dev
   ```

5. Open your browser and visit `http://localhost:5173`

## Components

### Core Components
- **Home:** Main landing page with featured content
- **OurShop:** Pet shop listings and browse
- **Product:** Individual pet details
- **AllCart:** Shopping cart management

### Dashboard Components
- **DashboardPuppys:** Pet management dashboard
- **DashbordServices:** Service management
- **DashBoardReviews:** Review management

### Service Components
- **Appointment:** Appointment scheduling
- **FindPuppy:** Search for puppies
- **FindTrainer:** Search for trainers
- **BathService:** Bath and grooming services
- **HealthServices:** Health and veterinary services

### User Components
- **Authentication:** Login and registration
- **MyAccount:** User profile management
- **Payment:** Payment processing

### UI Components
- **Shared:** Reusable UI components
- **FeaturedPost:** Featured content display
- **FeaturedService:** Featured services
- **PopularBread:** Popular pet breeds
